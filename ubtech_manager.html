通訊記錄

角度控制 (0x01 設置角度)

0° 240°
運動時間單位 20ms（0 = 全速轉動）。目標角度最大有效值 240°，單位 1 度。
鎖定時間單位 20ms：從舵機開始轉動起計時，未結束前舵機不再響應新的角度指令；到位後如外力導致偏移會強制修正。0 = 不啟用鎖定。

角度偏移量校正 (0xD2 / 0xD4)

範圍 -30° 至 +30°（內部單位 1/3 度，即 -90～90），面向舵盤正值順時針。重新上電後會被清零。

修改舵機 ID (0xCD)

⚠️ ID 修改立即生效。除非總線上只有單一 servo，否則請勿使用廣播 ID=0 執行此操作。

Raw 指令送出

進階用途：直接輸入 8 個 hex bytes（ID + CMD + 6 data bytes），checksum 同 header(FA AF)/帧尾(ED) 會自動補上。

協議說明

1. 需支援 Web Serial API（Chrome / Edge 桌面版）。
2. USB-TTL half-duplex adapter 連接 servo bus，固定 115200bps, 8N1。
3. 主機指令格式：FA AF {ID} {CMD} D1 D2 D3 D4 {SUM} ED
4. Checksum = byte[2..7]（ID+CMD+D1..D4）相加後取低8位。
5. CMD 一覽：
  0x01 設置角度（D1=角度0-240, D2=運動時間, D3D4=鎖定時間；angle=0xFF 為強制中止）
  0x02 角度回讀（讀取後舵機失電）
  0xCD 修改ID（D2=新ID）
  0xD2 設置角度偏移量（D3D4=有符號16位，單位1/3度）
  0xD4 讀取角度偏移量
6. 讀取版本使用獨立 header FC CF {ID} 01 00 00 00 00 {SUM} ED。
7. 單byte回覆：成功=0xAA+ID，失敗=無回應（修改ID失敗回覆0xEE）。
8. 此協議源自「某宝白菜价白牌总线舵机研究记」項目（拆解 mega8 韌體反組譯得出），與 UBTECH 優必選機器人關節舵機同源。
協議依據 某宝白菜价白牌总线舵机研究记 項目內 doc/UBTECH_protocol_detail.pdf 逐字核對實作。使用時請注意舵機獨立供電（勿只用USB供電），通信板電源與舵機電源需共地。
